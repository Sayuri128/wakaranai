# Dictionaries

`en_words.txt` is the English list from
[FrequencyWords](https://github.com/hermitdave/FrequencyWords) by Hermit Dave
(`content/2018/en/en_50k.txt`, built from OpenSubtitles 2018), reduced to words made of
letters and apostrophes, one per line, in frequency order. It is licensed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), and so is this derived list.

It is used to correct text-recognition mistakes on comic lettering before page translation.
